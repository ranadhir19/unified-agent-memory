The idea

Every harness keeps its own walled garden of context; switch tools and you start from zero. This project keeps memory outside the harness. Lifecycle hooks passively log every session event into one graph. An offline dream phase distills events into durable markdown memories that are merged, never appended — contradictions rewrite the note. On the next session start, in any harness, the profile memories are injected into context.

The extension beyond the original design: adapters to third-party data sources feed the same graph, each record carrying provenance. A fact that exists only in a GitHub issue, a Slack thread, or an RSS item becomes memory a coding agent recalls — memory belongs to the user, not the tool.

Pieces

Hook runtime

One uam-hook entrypoint for all three harnesses, with generated per-harness configs and each harness's real injection contract.

Graph store

A GraphStore protocol with two implementations: Neo4j (the article's linked-list event graph) and an identical in-memory store for zero-service runs.

Dream phase

Deterministic, fully offline distillation by default; an optional LLM distiller sits behind a provider seam.

Source adapters

GitHub, files, RSS, Slack exports — normalized records with SOURCED_FROM provenance, idempotent ingest.

Access layer

FastAPI REST + Strawberry GraphQL, an MCP server for on-demand CRUD, and a React demo UI with the cross-harness timeline.

Experiments

Seeded, reproducible, end-to-end through the real hook entrypoint — with honest conclusions and limitations.

Quickstart

pip install -e .
python3 examples/quickstart.py   # hooks in -> dream -> recall in another harness
uam-config claude-code           # ready-to-install hook configs (also: codex, cursor)
uam-ingest github octocat hello-world
python3 experiments/run_experiments.py
